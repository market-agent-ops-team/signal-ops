01 / Technical research

A direction, not a price target.

V1 uses XGBoost to classify the next three trading observations as UP, FLAT, or DOWN. A forward return above +0.75% is UP; below −0.75% is DOWN; the band between is FLAT. Reports map these to bullish, neutral, and bearish.

Development universe
INFY, TCS, WIPRO, HCLTECH
Data window
2020-01-01 to 2024-01-01 · yfinance
Split
Chronological shared dates · 70 / 20 / 10
Leakage controls
Three-row boundary purge; train-only scaler

Training and inference share the indicator builder and fixed 2020-01-01 history origin. All tickers on the same date belong to the same split. Serving reads the saved V1 artifacts; evaluated candidates require manual promotion.

The twelve model features

dist_ema_21 · dist_sma_50 · rsi_14 · macd_hist · bb_width · bb_pct · vol_ratio · obv_divergence · return_1d · return_3d · return_5d · volatility_5d

Training configuration

300 estimators, learning rate 0.03, max depth 4, subsample 0.8, column subsample 0.8, balanced sample weights, and early stopping after 30 rounds. The documented run selected iteration 31, with best log loss 1.095.

02 / News & interpretation

Two independent inputs.
One explicit comparison.

The news researcher queries NewsAPI over a seven-day window, filters for company relevance, scores articles with VADER, and aggregates by majority sentiment. VADER is a general-purpose lexicon, not a finance-tuned model.

Available

Relevant articles were observed and classified as bullish, bearish, or neutral.

Empty

The request returned no relevant articles. No sentiment was observed.

Unavailable

A missing key, provider restriction, network error, or invalid response prevented news research. No sentiment was observed.

The analyst flags divergence only when one input is bullish and the other bearish. Matching directional signals are aligned; neutral combinations do not establish directional alignment. The editor assembles the signal, headlines, reasoning, and limitations into Markdown.

What happens when I request a report?

Inputs are normalized and validated, then the shared API orchestration checks Redis. A valid hit skips research. A miss runs the LangGraph pipeline in a worker thread, validates its output, and caches the final JSON for 900 seconds by default. Redis failures fall back to uncached analysis.

04 / Boundaries

Know what remains uncertain.

  • Market regimes change. A small four-stock development universe does not establish broad generalization.
  • Historical data can be revised; adjusted prices and history initialization affect indicators.
  • The maximum class probability is not independently established as calibrated confidence.
  • News coverage and historical access depend on the provider and API plan. An as-of date does not guarantee point-in-time completeness.
  • No transaction costs, execution assumptions, or strategy returns are evaluated here.
Can I use other NSE tickers?

The input accepts NSE symbols, with an optional .NS suffix. Other exchange suffixes are rejected. V1 development evidence covers only INFY, TCS, WIPRO, and HCLTECH; a valid symbol still needs sufficient historical data.

Why can't I pick a future date?

The date is the as-of point: indicators are built from data on or before it, and the model classifies the three trading observations after it. A future date has no market data yet, so the analysis would silently reuse the latest session while wearing a future label. Pick today to predict the near future.

Why can a report be unavailable?

Missing saved model files produce a 503 response. Invalid or unavailable analysis data produces 422. Other pipeline failures produce a generic 500. Your input values stay in the form so you can retry or adjust them.

What does the site remember?

Only your Light, Dark, or System appearance preference is stored in a browser cookie, for up to one year. The shared server cache stores validated analysis responses by ticker and date; it is not a personal browsing history.
